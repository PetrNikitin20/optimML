# Статья для SUMMA 2026

`SUMMA2026_RU_gradient_geometry.docx` — русскоязычная рабочая редакция статьи «Геометрия градиента и LoRA-адаптация при обучении по предпочтениям».

`SUMMA2026_EN_gradient_geometry.docx` - полная английская редакция для подачи в SUMMA 2026. В видимом тексте отсутствует символ длинного тире `—`; формулы Word, таблицы и английская версия рисунка сохранены.

Документы построены на основе официального IEEE A4-шаблона конференции и содержат редактируемые формулы Word (OMML), линейный эксперимент, LoRA-адаптацию BERT-tiny и внешний пилот TinyLlama 1,1B на RewardBench. Единственный автор обеих версий - Никитин Петр Владимирович, к.пед.н., доцент, доцент кафедры искусственного интеллекта Финансового университета при Правительстве Российской Федерации.

Каталог `template` содержит неизменённый официальный Strict OOXML-файл и нормализованную Transitional OOXML-копию, использованную для программной сборки.
