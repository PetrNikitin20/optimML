# Статья для SUMMA 2026

`SUMMA2026_RU_gradient_geometry.docx` — русскоязычная рабочая редакция статьи «Геометрия градиента и выбор логистической потери при обучении по предпочтениям».

Документ построен на основе официального IEEE A4-шаблона конференции и содержит редактируемые формулы Word (OMML). Перед подачей требуется английская версия и замена заполнителя электронной почты/ORCID автора.

Каталог `template` содержит неизменённый официальный Strict OOXML-файл и нормализованную Transitional OOXML-копию, использованную для программной сборки.
